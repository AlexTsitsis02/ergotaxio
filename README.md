# Ergotaxio — δημόσια επίδειξη

Στατική επίδειξη εφαρμογής για τεχνικά γραφεία και εργοτάξια στην Ελλάδα. Περιλαμβάνει το περιβάλλον γραφείου και την πύλη λογιστή, χωρίς σύνδεση και χωρίς να απαιτείται ο υπολογιστής του δημιουργού να παραμένει ανοιχτός.

## Περιεχόμενο

- 67 σελίδες με ελληνικό interface και responsive διάταξη.
- 6 φανταστικά έργα, 8 προμηθευτές υλικών, 12 παραστατικά / παραλαβές και 5 παραγγελίες.
- 25 κατηγορίες εργασιών, 5 συνεργάτες εργασιών και 32 διακριτές συμβάσεις.
- 64 γραμμές κόστους, 32 πιστοποιήσεις, 22 πληρωμές / προκαταβολές και σχετικά αρχεία.
- Λεπτομέρειες, σημειώσεις και χρονολογικά ιστορικά από τα demo δεδομένα.
- Αναζήτηση και φίλτρα στον browser, προβολή / λήψη συνθετικών PDF και εξαγωγή CSV.
- Προεπισκόπηση φορμών για νέα παραλαβή, έργο, σύμβαση, εργασία, πιστοποίηση και καταβολή.

Όλα τα στοιχεία είναι φανταστικά και δημιουργήθηκαν από τους seeders της αρχικής εφαρμογής σε νέα, απομονωμένη βάση. Δεν χρησιμοποιήθηκε η τρέχουσα βάση εργασίας. Δεν περιλαμβάνονται πραγματικά έγγραφα, Excel αναφοράς, στοιχεία σύνδεσης, SMTP credentials ή `.env`.

## Τι λειτουργεί στην επίδειξη

Η πλοήγηση, η αναζήτηση, τα φίλτρα, οι λεπτομέρειες, τα dialogs, η πύλη λογιστή και οι λήψεις δουλεύουν ως στατικές σελίδες / JavaScript. Οι διαδρομές και τα assets είναι σχετικά, ώστε να λειτουργούν μέσα στο υποφάκελο του GitHub Pages.

Οι φόρμες παρουσιάζουν τη ροή και δεν αποθηκεύουν αλλαγές σε server. Δεν γίνονται πραγματικά uploads, αποστολές email, πληρωμές ή authentication. Τα πεδία κωδικών είναι απενεργοποιημένα. Η πλήρης Laravel εφαρμογή παραμένει ξεχωριστή.

## Ενεργοποίηση GitHub Pages

1. Το repository πρέπει να είναι Public για χρήση με GitHub Free.
2. Στο **Settings → Pages → Build and deployment → Source**, επίλεξε **GitHub Actions**.
3. Στο **Actions → Publish Ergotaxio demo**, εκτέλεσε **Run workflow** αν δεν ξεκίνησε ήδη από το push.
4. Μετά την επιτυχή δημοσίευση, το GitHub εμφανίζει το πραγματικό δημόσιο URL στη σελίδα Pages και στο deployment.

Το workflow `.github/workflows/pages.yml` δημοσιεύει αυτά τα στατικά αρχεία. Δεν απαιτούνται Composer, PHP server, Node build, database ή συνδρομή hosting. Επόμενα pushes στο `main` ενημερώνουν την επίδειξη.

## Τοπική προεπισκόπηση

Από τον φάκελο του repository:

```text
python -m http.server 8011 --bind 127.0.0.1
```

Άνοιξε `http://127.0.0.1:8011/`. Χρησιμοποίησε HTTP server για τη φόρτωση του JSON και όχι άνοιγμα του `index.html` ως τοπικό αρχείο.

Οι γραμματοσειρές είναι τοπικές· η άδειά τους βρίσκεται στο `assets/fonts/OFL.txt`.
